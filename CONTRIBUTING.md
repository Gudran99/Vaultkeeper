# Contributing

Contributions to documentation, tests and code are welcome. Open an issue before major changes. Work on a separate branch and describe your changes and tests in a pull request.

Use synthetic credentials and test vaults only. Never commit real passwords, tokens, recovery codes, vault files or personal data. Report security concerns privately as described in [SECURITY.md](SECURITY.md). Preserve existing licensing notices. Original contributions are licensed under the project's [MIT License](LICENSE). Third-party materials must retain their applicable licenses.
