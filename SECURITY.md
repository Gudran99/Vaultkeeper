# Security policy

Vaultkeeper is currently a development preview and has not undergone an independent security audit. Do not use it for production or sensitive credentials without appropriate review.

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub private vulnerability reporting if enabled. Do not include real passwords, vaults, recovery codes, tokens or personal data in reports. If private reporting is unavailable, request a private reporting channel without posting vulnerability details publicly.

## Review priorities

- Cryptographic implementation and vault file integrity
- Local browser bridge authentication and origin validation
- Clipboard, temporary files, backups and automatic locking
- Linux WebView sandbox configuration

No response-time guarantee or supported release schedule has been established.
